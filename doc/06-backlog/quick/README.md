# Tareas Ligeras y Notas Rápidas (`06-backlog/quick/`)

Este directorio almacena notas ligeras `QUICK_<slug>.md` generadas automáticamente cuando una tarea inicia desde el punto de entrada directo `TODO` (`-Phase TODO` o `--phase TODO`), evitando crear documentos completos de Requisitos o Plan cuando no aportan valor.

Ver guía completa en [`MANUAL_WORKFLOW.md`](../../00-governance/MANUAL_WORKFLOW.md).
