# Requisitos y planes en curso (`06-backlog/plans/`)

Aquí viven los `REQ_<slug>.md` y `PLAN_<slug>.md` de las épicas abiertas (los crea `new_lifecycle_task.py`).
Cuando la épica se cierra, lo que sigue vigente pasa a su runbook (`doc/04-operations/`) o a un ADR
(`doc/02-adr/`), y el REQ y el PLAN se borran. Quedan en el historial de git.

Ver [`MANUAL_WORKFLOW.md`](../../00-governance/MANUAL_WORKFLOW.md).
